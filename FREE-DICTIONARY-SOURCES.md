# Free online dictionary sources

The My Dictionary screen uses these sources only; no paid API key or subscription is required:

1. **Free Dictionary API** — https://dictionaryapi.dev/ — English definitions, parts of speech, phonetic spelling, example sentences, synonyms, and pronunciation audio when supplied. The app requests an entry only after the local vocabulary has no match.
2. **MyMemory Translation API** — https://mymemory.translated.net/ — attempts English-to-Tamil translation for the searched word and example. Free service availability and usage limits apply. If translation is unavailable, the app leaves Tamil blank and lets the learner enter it manually.

Successful online lookups are cached in local storage. The next search for that word can display the cached entry offline. Existing vocabulary and My Practice Words remain stored locally. Deleting a practice word does not erase the online dictionary cache.

The online services need an internet connection and can be temporarily unavailable. No paid fallback is configured.
