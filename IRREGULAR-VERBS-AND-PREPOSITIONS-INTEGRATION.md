# Lela grammar updates

This complete project ZIP is based on the latest `Lela-Prepositions-Practice-Updated` source archive. Existing app files and features are preserved.

## Prepositions
- Existing Prepositions route and navigation entry retained.
- Includes the 500-example preposition data file and Practice / Preposition list screens.
- Search supports English prepositions and Tamil meanings; practice gives choices, Tamil meaning, example, feedback, score and progress.

## Irregular verbs
- Added `src/app/features/irregular-verbs/irregular-verbs.component.ts`.
- Added lazy route `/irregular-verbs` and a navigation item.
- Search across V1, V2, V3, V-ing and Tamil meaning; table and typing practice for V2, V3 and V-ing.
- The included list is a starter list of common irregular verbs, not 3,000 irregular verbs.

## Run
1. Extract the ZIP.
2. Open the `my-english-buddy` folder.
3. Run `npm install`.
4. Run `npm run build`.
5. For Android, run `npm run android:sync` after Android tooling is configured.
